# ML-w-KMD

A collection of machine learning fundamentals notebooks, plus a brain tumor image classification project.

## Contents

**Fundamentals notebooks**
- `OLS_RidgeRegression.ipynb`, `RidgeRegression_Noninvertible.ipynb`, `Ridge_Visualization.ipynb`: linear and ridge regression
- `logistic regression.ipynb`, `Logistic_Regression_Regularization.ipynb`: logistic regression and regularization
- `CrossEntropyLoss.ipynb`: cross-entropy loss
- `One-Hot_encoding.ipynb`: one-hot encoding
- `perceptron.ipynb`, `XOR.ipynb`, `Spiral_NN.ipynb`: perceptron and neural network examples

**Brain tumor classification**
- `brain_tumor_dataset/`, `yes/`, `no/`: image data
- `classification.ipynb`, `brain_tumor_model.ipynb`: Predicts whether an MRI image has a tumor present or not

**Data**
- `logistic_regression_data.csv`: data used in the logistic regression notebooks

## Requirements

- numpy, matplotlib, plotly, scikit-learn, keras, tensorflow 

## How to run

1. Clone the repo: `git clone https://github.com/EUNICE-glitch/ML-w-KMD.git`
2. Install the requirements above.
3. Open any notebook in VS Code or Jupyter and run the cells in order.
